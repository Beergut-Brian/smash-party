# 🚗💥 Smash Party

A co-op smash-'em-up for little kids and their grown-ups. Drive wacky cars, wreck everything, fill the smash meter together. Nobody loses.

**Play:** open the GitHub Pages link in Chrome, press **F** for fullscreen, and each player presses **A** on a controller to join.

| | Controller | Player 1 keys | Player 2 keys |
|---|---|---|---|
| Drive | Left stick (point where to go) | W A S D | Arrows |
| Turbo | A / RT | Space | Enter |
| Jump | B | E | Right Shift |
| New car | X / Y | Q | / |

Run locally: `python3 -m http.server` then open http://localhost:8000.
